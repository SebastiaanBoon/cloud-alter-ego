# Learnings per routine

One file per routine: `skills/learnings/<routine>.md`. A routine reads it at the start and appends to it
after every run, see `skills/routines.md`. Format of a new file:

```
# Lessons <routine>

## Rules

## Log
```

- **Rules:** short, always-valid instructions, promoted from the log. They beat the routine's own approach.
- **Log:** one line per run: `YYYY-MM-DD | what worked | what failed and the real cause | next time`.

A good lesson is concrete and reusable ("the form only shows the URL field after ticking remote"), names the
real cause and not the symptom, and records what worked as well as what failed. Never put secrets,
credentials or personal data in these files.
